    划词翻译

    详解会另外发一次请求（约多花一条翻译的额度），给出分词性的释义、双语例句、用法辨析和相关词，专有名词会说明是什么、在哪、为什么有名。自动模式只对 5 个英文单词 / 12 个汉字以内的短内容发起，长句子仍需手动点「详细解释」。同一个词的详解会缓存在本机，再划一次不重复计费。

    决定用哪个 API 地址和密钥。同一家服务商的话选「跟随翻译接口」即可

    翻译和详解可以用两个不同的模型。最常见的搭配：翻译用 qwen-mt-flash 这类翻译专用模型（便宜、专精），详解用通用对话模型（qwen-plus、deepseek-chat 等）。两者服务商相同时，接口选「跟随翻译接口」、这里只填模型名就行，地址和密钥都不用再配一遍；不同服务商才需要在上面「翻译接口」里另加一个接口，再到左边选它。翻译专用模型做不了详解——它们不看提示词，只会把原文再翻一遍。

    音标、发音与生词本

    划词卡片和快速翻译里，选中单个英文单词时会显示音标和真人发音；短语和句子没有音标，朗读会用系统语音合成。音标来自免费的 dictionaryapi.dev，不需要密钥，查询结果缓存在本机，查不到不影响翻译。

    同时决定挑哪条真人音频、以及语音合成用哪种嗓音

    1 为正常语速，听不清可以调到 0.8

    朗读需要联网：dict.youdao.com 是词典录音，只认单词和短词组，句子会失败；fanyi.baidu.com 是语音合成，整句、中文、日文都能读，1000 字以内。两者国内外都能直连，dictionaryapi.dev 的音频节点则经常返回 502。全都拿不到时改用系统语音合成——那条路不联网，但要求电脑装了对应语言的语音包。朗读的内容会发给对应服务商；介意就选「不联网」。

      备份与同步

      生词本、设置和 API Key 都存在本机浏览器里，平时不用管。换电脑或换浏览器时导出一个文件带走即可； 想让两台机器自动保持一致，再看下面的云同步。

      导出的文件含生词本、设置与接口配置。勾了云同步里的「同步 API Key」时，文件里的密钥是加密的，导入要填对主口令。

      云同步（两台机器 / 两个浏览器自动保持一致）

      把生词本、设置、接口配置和 API Key 同步到你自己的网盘或 GitHub，Chrome 和 Edge 填同一份配置就互通了。没有我们的服务器——数据只在你的账号里，扩展只负责搬运。API Key 会先用主口令在本机加密，云端拿到的是密文。

      存储位置与凭据

      填目录即可，扩展会在里面建 mikelingo-sync.json。

      坚果云要用「应用密码」，不是登录密码。

      细粒度 Token 勾选 Gists: Read and write；经典 Token 勾 gist 这一项即可。

      只留在本机，不会上传。两台浏览器必须填同一个口令才解得开对方的密钥；忘了口令就只能重填一次 API Key，我们也解不开。
